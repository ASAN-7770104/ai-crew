# Внедрение в бизнес

Порядок для того, кто ставит AI Crew клиенту. Весь срок 14 дней.

## До старта
- Один человек со стороны бизнеса, который принимает решения и отвечает на вопросы.
- Список того, что агентам запрещено.
- Подписка Claude, где доступны плагины.

## День 1. Установка и знакомство
```
/plugin marketplace add ASAN-7770104/ai-crew
/plugin install ai-crew@ai-crew
/ai-crew:company-setup
```
Результат: `company/COMPANY.md`, подтверждённый владельцем. Начните с трёх ролей, а не с двенадцати.

## Дни 2–4. Подключения
Только то, что нужно выбранным ролям, и сначала только чтение. Отправку писем, платежи и публикации не подключать.

## Дни 5–10. Работа под присмотром
- Каждой роли одна настоящая задача.
- Всё уходящее наружу проверяет и отправляет человек.
- Ошибки записывать: что агент сделал не так и какого факта ему не хватило.

## Дни 11–14. Разбор
- Что сэкономило время, а что пришлось переделывать.
- Лишние роли убрать, повторяющиеся действия описать навыком `sop-writer`.
- Договориться о еженедельном разборе `weekly-review`.

## Критерии приёмки
- [ ] `COMPANY.md` заполнен без выдуманных данных.
- [ ] Каждая включённая роль выполнила настоящую задачу.
- [ ] Ни одно действие наружу не ушло без согласия.
- [ ] Владелец называет хотя бы одну задачу, которую теперь делает быстрее.

## Без Claude Code
Откройте сайт-каталог, нажмите «Подробнее» у роли и «Скопировать инструкцию агента», затем вставьте её в инструкции проекта Claude. Навыки так же копируются и добавляются в проект файлами.
