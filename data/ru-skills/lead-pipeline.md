# Воронка лидов

## Оценка от 0 до 10
- подходит под портрет клиента: 0–3
- есть повод писать сейчас: 0–3
- известен человек, принимающий решение: 0–2
- есть бюджет по открытым признакам: 0–2

8–10 писать сегодня, 5–7 на этой неделе, ниже 5 не тратить время.

## Первое сообщение
Повод из жизни клиента, один вопрос, без прайса. До 60 слов.

## Правила
- У каждого лида следующий шаг и дата. Без этого лид считается брошенным.
- Агент готовит черновики. Отправляет человек.
- Отказавшимся повторно не пишем.
